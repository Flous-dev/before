# BEFORE

**Le HUB des soirées.** *Ce qui se passe sur BEFORE, reste sur BEFORE.*

👉 **Démo : [flous-dev.github.io/before](https://flous-dev.github.io/before/)**

Prototype d'application de soirée en français. Trois sections :

- **La soirée commence** — jeux à boire pour un groupe (rôles REF / SCAMER / PNJ, blackjack, sniper…)
- **HANGOVER** — albums photos de la soirée et classement des gorgées
- **AFTER** — les bars et clubs ouverts près de toi

## Technique

Une seule page, sans dépendance ni serveur : HTML, CSS et JavaScript natifs dans [`before.html`](before.html). Rien n'est envoyé sur internet — photos et scores restent dans le stockage local du téléphone.

Pour l'essayer en local, il suffit d'ouvrir `before.html` dans un navigateur.

## Sur téléphone

Ouvre le lien de la démo dans Safari, puis **Partager → Sur l'écran d'accueil** : l'app s'installe en plein écran avec son icône.
